Wildlife Shield Foundation

This is a basic 5-page website built to spread awareness about saving wild animals and forests in Kenya.

What's on the Website
- Home: What the organization is all about.
- Projects: Our work with the Mau Forest and elephants in the savannah.
- Get Involved: How people can join in and help.
- About Us: Who started this project and why.
- Contact Us: Simple ways to reach us in Nairobi.

How It Was Built
- Simple HTML pages
